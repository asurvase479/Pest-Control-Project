# Pest-Control-Project using Power BI 

End-to-end automated Marketplace Analytics solution(Volume Analysis) built with Python, Keepa API, and Power BI, replacing manual data collection, cost calculation, and reporting across 961 ASINs and $352M in annual revenue.
