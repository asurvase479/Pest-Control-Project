# Pest-Control-Project using Power BI 

End-to-end automated Marketplace Analytics solution built with Python, Keepa API, and Power BI, replacing manual data collection, cost calculation, and reporting across 961 ASINs and $352M in annual revenue.

Replaces manual Excel consolidation of 961 ASINs into one live view of units, revenue, brands and categories, with slicers for instant filtering.
